Code d'installation
Vous installez FIWAKTI depuis un autre poste que le serveur. Saisissez le code affiché par l'installateur (ou lisez-le dans donnees/jeton-installation.txt sur le serveur).

Bienvenue

Nous allons préparer votre installation de FIWAKTI en quelques étapes : vérification de la machine, licence, compte administrateur. Aucune donnée n'est modifiée avant la dernière étape.

Type d'installation

Vérification de la machine

FIWAKTI contrôle que tout est prêt. Seuls les points 🔴 bloquants empêchent l'installation.

  • Vérification en cours…

Licence

Collez la clé de licence reçue de l'éditeur. Elle indique le nom de votre entreprise et les modules ouverts.

Base de données

PostgreSQL déjà configuré pour ce serveur.
L'installateur Linux et Docker créent cette base automatiquement ; sinon, demandez ces informations à votre service informatique.

Compte administrateur

Ce compte gère l'installation. Vous choisissez son mot de passe : il n'est jamais transmis à l'éditeur.

    Reprise après sinistre

    Choisissez le trousseau de clés (fichier .key téléchargé depuis État du système) puis la sauvegarde à restaurer (fiwakti-….chiffre). Les comptes, le paramétrage, les badgeages, les clôtures et l'audit sont rétablis.

    ✅
